# Unnamed Medicare company — project bundle v1.2

Packaged October 17, 2026. Company name: undecided.

Start with `medicare-company-architecture/README.md`, then `ARCHITECTURE.md`. This is the current design: self-directed conversational research, transparent deterministic ranking and a licensed, appointed agent at purchase. Primary operating metric: human minutes per effective, retained policy.

## New in v1.2

Competitive position is auditable neutrality, not unbiased AI. Segments: caregivers first, self-directed researchers second, Medigap shoppers third. Distribution: direct caregiver content/search, then financial-advisor software and publishers, then health systems after outcome evidence. The 12–24 month incumbent-response window is a planning assumption. Build caregiver brand ownership, embedded integrations, self-serve conversion knowledge and published suitability/complaint/retention evidence. The edge is segment access and research capacity, not eliminating licensed labor.
