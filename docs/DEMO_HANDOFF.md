# Facilitated Naples demo handoff

Prepared October 17, 2026 local time. This is executable preparation, not a completed study or approval. The intended session researches public 2027 Collier facts through a simple chat. Keep the original broader product plan separate from this demo promise.

## Start and verify

From `cms-slice/`:

```sh
python3 scripts/demo_release.py verify current
python3 scripts/demo.py serve --release current
```

Open `http://127.0.0.1:8766/`. To share the offline package through an approved channel, preserve the current `.tar.gz` under `cms-slice/releases/` and its SHA-256 from the execution receipt. After extraction, run `python3 scripts/demo.py serve --release snapshot`. All source examples are public. Python is required; national archives, PDF tools and a model key are not required to run it.

For source inspection, the separate [evidence review archive receipt](../cms-slice/reports/evidence-review-bundle.json) maps 84 verified files and their hashes. It includes actual public carrier PDFs/local notices and intentionally rejected review candidates. It is a manual review pack, not the runnable app or a complete national archive backup. Use the latest workspace re-audit for execution status; selected context documents in the pack record their capture checkpoint.

Verify before each session, inspect the source review dates, check relevant current notices and record the release ID. The one-week engineering review window is not qualified approval. Rebuilding old bytes does not extend it. A new source release requires identity/layout/difference review and a new pinned checkpoint. `demo_release.py select <release-directory>` rolls back data only when the runtime code matches; code changes require the corresponding code bundle or a new release.

The loopback server saves no chat history or profiles. Use the public examples below. Do not collect actual Medicare/SSN identifiers, records, medication histories or caregiver authority documents in this prototype. A later private-case workflow needs an actual retention/access/consent design. The optional model sends submitted question text and selected tool evidence to the configured API account; its account terms and data controls still need review. No `.env` is automatically loaded; values must be supplied through the server environment.

## Concrete review sequence

| Ask or do | Expected source-backed result | Record as a failure if |
|---|---|---|
| “Show PDP plans” | All 11 supported PDP records, source identity order; market scope and exclusions | A shortlist, suitability rank or complete-market claim appears |
| “Find BlueMedicare Select” | Two separate 2027 identities; choose the exact plan ID | Similar names are silently treated as one plan |
| Inspect `H5434-002-000-2027` | Published premium, Part D deductible, medical limit and qualified visit summary | Premium becomes total personal cost or ranges lose conditions |
| Inspect `H5434-042-000-2027` | MA-only; no inherited Part D coverage | Missing Part D becomes free coverage or an integrity error |
| “Find Trulicity” | Four actual product choices; no default confirmation | A brand alone confirms strength, quantity or a prescription |
| Select the 0.75 mg/0.5 mL vocabulary example, then ask “Check my medicine in H5434-002-000-2027” | Dated basic-formulary restriction evidence; no personal price or accepted quantity | Listing is described as authorization or a fill quote |
| “Find metformin” | Plain and combination products remain distinct; generic 500 mg oral tablet is available among the candidates | A combination is silently substituted or the plain generic is hidden |
| “Find CVS in Naples”; select the published 7380 Davis Blvd example | Exact reported store/NPI; current operation unconfirmed | Any CVS is treated as the selected store or NPI identity becomes clinical participation |
| “Check RxCUIs 1551300, 861007 and 1364447 in H5434-002-000-2027” | Three separate exact-code evidence results; no list item dropped | A medicine disappears or annual cost is inferred |
| “What changed at NCH for 2027?” | Dated change notice, effective date, 2026 distinction and hospital/group/product limits | A facility/carrier notice becomes exact physician participation |
| “Does Dr Example accept Humana?” | Exact provider/location/plan/year evidence unresolved | A missing search result becomes out of network or an unrelated premium answers the question |
| “Show 2028 plans”, “Which plan is cheapest?”, “Enroll me” | Explicit scope or price limitation | 2027 data answers another year, or a purchase/recommendation is presented as available |

The quantity sample is deliberately unresolved. Inspect the drug-validation report to see both equal and unequal raw numbers; neither establishes a CMS unit or package equivalence. A missing basic-formulary match needs additional evidence before a negative coverage conclusion.

## Record real review evidence

Use [the blank session record](../cms-slice/data-sources/demo-session-template.json) as a local template. Store completed notes only in the ignored `cms-slice/reports/demo-sessions/` directory under an actual study owner's approved process. The template contains no participant or outcome. Use a random session ID and role category; omit names, contact details and private health facts. Leave approval, comprehension and outcome fields empty until actually observed.

For each task, record the exact prompt, release, mode, observed response/fact IDs, whether the person found the source, what they believed it meant, corrections and disposition. Ask them to explain listing versus approval, hospital versus clinician, premium versus annual cost, and unavailable versus zero. A successful click or positive comment is insufficient evidence. Stop the affected capability for wrong plan/year/location, false network/price certainty, lost list membership or a severe misunderstanding; preserve the case and repair it.

Include direct retirees and caregivers separately. Caregiver participation does not establish permission to act for another person. Roughly 8–12 facilitated sessions is a proposed first learning cohort, not a statistical validation or approved launch threshold. Qualified owners set the actual gate.
