Field Name           Type(size)   Description
CONTRACT_ID           Char(5)     Organization contract number assigned by CMS; the first letter of
                                  CONTRACT_ID signals the type of entity:
No data              No data            Hxxxx = Local Medicare Advantage (MA) plan

    No data          No data            Sxxxx = Stand-alone Prescription Drug Plan (PDP)

                                  are listed in “MA_REGION_CODE values” table.

                                  in “PBP_REGION_CODE values” table.
STATE                 Char(2)     2-character State code (applicable only for "H" contracts -- Local MA
                                  plans)
COUNTY_CODE           Char(5)     5-character SSA State/County code (applicable only for "H" contracts --
                                  Local MA plans); see Geographic Locater file
SNP                   Char(1)     Is this a Special Needs Plan and, if so, what type? (0=Not a SNP,
                                  1=Chronic or Disabling Condition, 2=Dual-Eligible, 3=Institutional)
