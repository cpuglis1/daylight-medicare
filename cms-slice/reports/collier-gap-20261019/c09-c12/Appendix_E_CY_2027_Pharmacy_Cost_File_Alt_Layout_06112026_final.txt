   PHARMACY COST FILE
   Note: For use only when a Part D sponsor opts to establish a different dispensing fee for selected drugs.
   Unique record identifiers: CONTRACT_ID, PLAN_ID, SEGMENT_ID, and PHARMACY_NUMBER

                  Field Name                      Type(Size)          NULL                               Field Description
   CONTRACT_ID                                  Char(5)          NOT NULL          Organization’s contract number that is assigned by CMS.
                                                                                   Example: H9999
   PLAN_ID                                      Char(3)*         NOT NULL          Plan ID assigned by CMS that is associated with this
                                                                                   pharmacy cost file. Include leading zeros. Example: 001
   SEGMENT_ID                                   Char(3)*         NOT NULL          Segment ID associated with the plan ID that is associated
                                                                                   with this pharmacy cost file. Include leading zeros.
                                                                                   Example: 001

                                                                                   Note: If the plan is not segmented, use 000 for this field.
   PHARMACY_NUMBER                              Char(12)         NOT NULL          This is the 12-digit pharmacy number.
                                                                                       • 10 digit NPI number with leading one and zero
   PRICE_ID                                     Number(3)        NOT NULL          Price file grouping number to be used at this pharmacy.
   BRAND_DISPENSING_FEE_30                      Currency(12)     NOT NULL          In addition to the ingredient cost (product cost) at the point
                                                (Format:                           of sale for a 30 day supply.
                                                $$$$$$$$cccc)
   GENERIC_DISPENSING_FEE_30                    Currency(12)     NOT NULL          In addition to the ingredient cost (product cost) at the point
                                                (Format:                           of sale for a 30 day supply.
                                                $$$$$$$$cccc)
   VACCINE_ADMINISTRATION_FEE                   Currency(12)     NOT NULL          For vaccines only: In addition to the ingredient cost
                                                (Format:                           (product cost), the maximum fee associated with the
                                                $$$$$$$$cccc)                      administration of any covered vaccines at the pharmacies in
                                                                                   this price ID.
