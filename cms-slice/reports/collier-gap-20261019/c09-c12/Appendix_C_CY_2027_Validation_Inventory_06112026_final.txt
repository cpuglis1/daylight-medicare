Error Key:


         Error Type                                                                     Description

 Fatal (Level 1)               •   These errors are presented directly on the submission page in HPMS. They are not reflected in the module reports.
                               •   If a submission receives one or more fatal errors during level 1 processing, the file will not be uploaded to HPMS.
                               •   The plan must correct the fatal error(s) and resubmit the zip file to HPMS within the applicable submission window.
                               •   If the last submission in week one has one or more fatal errors, the plan will not be permitted to resubmit in week two, and
                                   the contract will be suppressed in Medicare Plan Finder (MPF).


 Fatal (Level 2)               •   The plan must correct the fatal error(s) and resubmit the zip file to HPMS within the applicable submission window.
                               •   If the last submission in week one has one or more fatal errors, the plan will not be permitted to resubmit in week two, and
                                   the contract will be suppressed in MPF.
                               •   If the last submission in week two has one or more fatal errors, the contract will be suppressed in MPF.


 Non-Attestable Suppressible   •   The plan must correct the error(s) and resubmit the zip file to HPMS within the applicable submission window.
                               •   If the data is not corrected and resubmitted within the applicable submission window, the contract will be suppressed in
                                   MPF.


 Attestable Suppressible       •   The plan may correct the finding(s) and resubmit the zip file to HPMS within the applicable submission window.
                               •   Alternatively, the plan may attest to the finding(s) in HPMS prior to the attestation deadline.
                               •   If the data is not corrected and resubmitted within the applicable submission window, or if an attestation is not submitted
                                   for the finding(s) in HPMS, the contract will be suppressed in MPF.


 Informational                 •   If desired, the plan may correct the finding(s) and resubmit the zip file to HPMS within the applicable submission window.
                               •   Otherwise, the data will be displayed on MPF.
