# Contributing to Daylight

Start with [the current project hub](docs/project/README.md), then read [the contributor workflow and ownership guide](docs/project/CONTRIBUTING.md). [PRINCIPLES.md](PRINCIPLES.md) and the applicable `AGENTS.md` govern changes.

The GitHub destination is public. Use the [publication and cloud handoff](docs/project/CLOUD_HANDOFF.md) before selecting files for a commit. Current local research, private state and uncommitted code are not automatically part of a safe or reproducible public checkout.
